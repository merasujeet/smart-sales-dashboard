## Installation

### 1. Clone the repository
git clone https://github.com/merasujeet/smart-sales-dashboard.git
### 2. Open the project

```bash
cd smart-sales-dashboard
```
### 3. Install required packages

```bash
pip install flask mysql-connector-python werkzeug
```
### 4. Configure MySQL

- Start MySQL Server.
- Create the `sales_dashboard` database.
- Configure your MySQL username and password in `app.py`.
### 5. Run the application

```bash
python app.py
```

Open your browser:

http://127.0.0.1:5000/
